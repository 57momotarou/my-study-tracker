# Study Tracker v67

## いつものホーム画面のアプリを更新する

1. 更新前にアプリの歯車 → データ →「バックアップを保存」で記録を控えます。
2. `study-update.zip`を解凍し、`my-study-tracker`フォルダーを開きます。
3. **中身のファイル一式**を、GitHubの今の`index.html`がある場所へ上書きしてコミットします。ZIPそのものをアップロードしたり、余分なフォルダー階層を増やしたりしないでください。
4. GitHub Pagesの公開処理が成功するまで待ちます。変更の反映に最大10分程度かかる場合があります。
5. スマホをオンラインにして、いつものホーム画面のアイコンから開きます。新版を取得すると自動で切り替わります。

今のリポジトリ・公開ブランチ・公開フォルダー・URLはそのまま使ってください。ホーム画面への追加し直しは、通常のアプリ更新には必要ありません。同じ端末・同じ配信元の学習記録は維持されます。別端末への同期機能はありません。

旧版からの最初の更新で反映しないときは、一度アプリを完全に閉じて開き直してください。v67では起動時だけでなく、アプリへ戻ったときにも確認します。歯車 → データに「v67」と出れば今回の更新版です。「更新を確認」ボタンも使えます。申請予定の入力中は、保存するか「入力をクリア」を押した後に切り替わります。

GitHub Pagesが別のブランチ／フォルダーを公開している場合は、そちらを更新する必要があります。このZIPを受け取った時点ではGitHub上のファイルは変更されていません。

## 追加した機能

- **成績・GPA**：進捗 → 成績・単位。A/B/C/D/F/K/Pを選ぶと自動保存。Fを含みK/Pを除く参考GPAと、重複を除いた修得単位を表示します。
- **課題・期末**：進捗 → 動画・課題 → 各科目の課題・期末欄。動画とは別に記録します。既存の動画記録は全学期共通、課題・期末・成績は学期別です。
- **申請予定**：予定の下部から登録・編集・対応済み・削除。日時は日本時間で入力します。
- **カレンダー出力**：予定 → 端末カレンダーに書き出す。確定済みの授業締切・期末締切と自分の申請予定を.icsファイルにします。概算や日時未確認の予定は除きます。出力後の変更は自動同期されません。再取込時に重複する場合があるので専用カレンダーへの取込をおすすめします。通知はカレンダー側で設定してください。

## データの引き継ぎ

バックアップには新機能の記録も入ります。旧版のバックアップも読み込めますが、その場合は成績・課題・期末・申請予定が空になります。復元前の確認に内容を表示します。新しいバックアップは、追加記録が失われないよう旧アプリでは読み込めません。

参考GPAは全履修回を集計します。Pの単位認定の区分や再履修の扱い、卒業・出席・受験可否は大学の案内で確認してください。

## 開発・検証

ビルド不要。`python3 -m http.server 8000`で開けます。開発の前にAGENTS.mdとHANDOFF.mdを読んでください。

Node回帰チェック34件、Chromiumで旧版からの更新・保存／復元・入力操作・オフライン動作・スマホ幅とPC幅を確認済み。iPhone実機／Safari・端末カレンダーへの取込・実際のGitHub公開は未確認です。
