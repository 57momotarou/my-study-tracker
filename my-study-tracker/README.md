# Study Tracker v70 更新手順

`study-patch-v70.zip` は、直前に配布したv69から変更した公開用14ファイルだけです。未変更のアイコン等は含めません。v69を適用済みのアプリへ上書きしてください。

## 更新の順番

1. 更新前に、歯車 → データでバックアップを保存します。
2. ZIPを解凍し、中のファイルをGitHubの同名ファイルへ上書きしてコミットします。ZIPそのものはアップロードしません。既存の未変更ファイルは残します。
3. 公開処理の完了後、オンラインでいつものホームアイコンからアプリを開きます。歯車 → データでv70を確認してください。必要なら「更新を確認」を押します。
4. 今回は大学資料・生活時間のJSONを変更していません。v69で読み込み済みなら、非公開JSONの読み直しは不要です。履修・学習記録・生活時間・勉強しない日は引き継ぎます。

同じ公開元・URLを維持してください。通常更新でホーム画面への追加し直しは不要です。この配布物はGitHubへ直接反映したものではありません。

## 今回の変更

- 申請・自分の予定：スマホ幅では日付と時刻を縦に並べ、入力欄を枠内に収めました。
- バッジ：必要科目の全コマと期末が完了すると、アプリ内で「獲得済み」になります。全学期の記録を使い、同じ科目の別学期の途中記録を足し合わせません。課題・成績・大学の正式な発行状況とは別の学習完了表示です。
- 欲しいバッジの「目標にする」で登録・解除できます。上部に目標がまとまり、目標だけ／獲得済みだけの絞り込みもできます。
- バッジの詳細に必要科目と完了・未完了、履修登録状況を表示。前提バッジの科目、どれか1科目の選択条件、分野別単位の科目候補も確認できます。卒研テーマなどの追加条件は、詳細の確認済みチェックを併用します。
- 1週間：今日を一番上にして、今日を含む7日間を表示します。開始日の手動変更と「今日から表示」に対応。日付が変わった後の復帰時にも今日から表示します。
- 先取り推奨：予定タブの割当日時が早い科目から表示し、次の予定日時も併記します。遅刻・直近7日以内の締切は引き続き優先します。

## 「今日」の上部カード

登録済みの日程から、選択中の学期と履修科目に関係する期末試験・成績発表を知らせます。

| カード | 表示される期間・内容 |
| --- | --- |
| 期末試験開始前 | 開始14日前から。開始までの日数 |
| 期末試験期間中 | 開始〜締切。締切までの日数 |
| 期末試験終了 | 終了後3日間 |
| 成績発表 | 発表14日前〜3日後 |

受験済みのチェックでは消えません。日程のお知らせとして表示します。残日数は日本時間にそろえました。

## バックアップ

新しい出力はversion 4で、バッジ目標・追加条件確認も含みます。version 1〜3の復元にも対応しますが、古いバックアップには新しいバッジ項目がないため、復元時に空になることを確認画面で知らせます。v4は古いアプリへ戻せないため、復元先もv70以降へ更新してください。

## 大学資料の非公開化について

公開ソースから大学の日程・学生ガイドだけでなく、科目・バッジ・要件データと個人の生活時間も取り除きました。専用JSONを選んだ端末の中だけで読み込みます。学習記録とともにGitHubへ自動送信する機能はありません。

**以前の公開内容は、今回の上書きやファイル削除だけではGitHubの過去のコミットから消えません。** 実際のリポジトリと履歴は未確認です。過去履歴を含めて非公開にするには、リポジトリの公開設定と履歴の整理が別途必要です。リポジトリをPrivateにしても、GitHub Pagesの公開ページが自動的に非公開になるとは限りません。公開を直ちに止めたい場合は、先にPagesを非公開（unpublish）にする方法があります。その間オンライン利用はできなくなります。

手順の根拠：
- [GitHub Pagesの公開元と公開範囲](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
- [GitHub Pagesサイトの公開停止](https://docs.github.com/en/pages/getting-started-with-github-pages/unpublishing-a-github-pages-site)
- [Git履歴から機密データを削除する](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)

端末内保存は、パスワード付きの保管庫ではありません。同じ端末・ブラウザーを使える人は内容を見られます。専用JSONとバックアップは手元に保管し、公開・共有しないでください。
