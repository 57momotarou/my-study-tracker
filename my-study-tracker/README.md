# Study Tracker v69 更新手順

今回の `study-patch-v69.zip` は、前回配布したv68から**変更した公開用8ファイルだけ**です。v68を適用済みのアプリへ上書きしてください。未適用の場合は先に前回のstudy-patch.zipを適用します。未変更のアイコン等は入っていません。

## 更新の順番

1. 更新前のアプリで、歯車 → データ → バックアップを保存します。バックアップは手元に保管してください。
2. study-patch-v69.zipを解凍し、中のファイルをGitHubの既存index.htmlと同じ階層へ上書きしてコミットします。ZIPそのものはアップロードしません。既存の未変更ファイルは残します。
3. 公開先に `AGENTS.md`、`HANDOFF.md`、`REVIEW.md`、`tests/` がある場合は削除してください。古い配布ZIP・元資料・非公開JSON・バックアップのコピーも公開しないでください。
4. GitHub Pagesの公開処理が成功したら、スマホをオンラインにしていつものホームアイコンから開きます。必要なら一度閉じて開き直してください。
5. 歯車 → データ → 非公開データを読み込むで、今回更新した `study-private.json` を選び、確認後に読み込みます。生活時間を今回の設定に更新するため、以前読み込んだ端末でも必要です。**このJSONはGitHubへアップロードしません。** 履修・進捗・成績は保持します。
6. 歯車 → データでv69を確認します。別のスマホ・ブラウザーでも非公開データの読み込みが必要です。

同じGitHub Pagesの公開元・URLを維持してください。通常更新でホーム画面への追加し直しは不要です。この配布物はGitHubへ直接反映したものではありません。

## 大学資料の非公開化について

公開ソースから大学の日程・学生ガイドだけでなく、科目・バッジ・要件データと個人の生活時間も取り除きました。専用JSONを選んだ端末の中だけで読み込みます。学習記録とともにGitHubへ自動送信する機能はありません。

**以前の公開内容は、今回の上書きやファイル削除だけではGitHubの過去のコミットから消えません。** 実際のリポジトリと履歴は未確認です。過去履歴を含めて非公開にするには、リポジトリの公開設定と履歴の整理が別途必要です。リポジトリをPrivateにしても、GitHub Pagesの公開ページが自動的に非公開になるとは限りません。公開を直ちに止めたい場合は、先にPagesを非公開（unpublish）にする方法があります。その間オンライン利用はできなくなります。

手順の根拠：
- [GitHub Pagesの公開元と公開範囲](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
- [GitHub Pagesサイトの公開停止](https://docs.github.com/en/pages/getting-started-with-github-pages/unpublishing-a-github-pages-site)
- [Git履歴から機密データを削除する](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)

端末内保存は、パスワード付きの保管庫ではありません。同じ端末・ブラウザーを使える人は内容を見られます。専用JSONとバックアップは手元に保管し、公開・共有しないでください。

## 今回変わった予定画面

- 月 → 1週間 → 全体の順に変更し、最初に月を表示します。1日の生活時間割画面は削除しました。
- 月の各日に、その日にやる科目・コマを表示します。日付をタップすると下に学習時間と締切、視聴・課題・期末の記録ボタンを表示します。
- 月カレンダーのダブルタップを追加対策で抑止しました。拡大による下タブの位置ずれを防ぎ、通常のスクロールとピンチ操作は維持します。
- 非公開JSONの生活時間から、通常の学習枠を優先して割り振ります。締切2日前の完了を目標に、必要な期間は予備枠も使います。
- 勉強できなかった分は、完了記録を基準に、次に予定画面を開いたとき・画面復帰時・表示中の更新時に再配置します。「この日は勉強しない」で事前に除外もできます。完了した視聴と課題は、それぞれ記録してください。
- 確保できない量や既に期限を過ぎたものは「要調整」として知らせます。締切後に移して間に合う表示にはしません。概算の締切や未確認の期末日時には注意表示を出します。

閉じたアプリがバックグラウンドで実行を続ける仕組みや、OSカレンダーとの自動同期はありません。アプリ内の残り時間に収まらない学習量まで、締切を保証するものではありません。

既存のコマ・期末・成績・バッジ・履修設定・カレンダー書き出しは維持しています。バックアップversion 3には非公開資料と勉強しない日も含まれます。旧version 1/2も復元できます。JSON・バックアップはGitHubに載せないでください。
