# Study Tracker v72 更新手順

`study-patch-v72.zip`は、直前に配布したv71から変更・追加した公開用ファイルだけです。v71を適用したアプリへ上書きしてください。

## 更新

1. 歯車 → データで、更新前のバックアップを保存します。
2. ZIPを解凍し、中のファイルをGitHubの同じ場所へ上書きします。新しい`enrollment-simulation.js`・`quiz-records.js`・`app-help.js`も追加し、コミットしてください。ZIPそのものはアップロードしません。
3. 公開処理の完了後、いつものアプリをオンラインで開きます。歯車 → データでv72を確認し、必要なら「更新を確認」を押してください。

同じURLへの更新では、既存の履修・進捗・成績・学習日・目標・自分の予定を引き継ぎます。専用JSONの読み直しやホーム画面への追加し直しは不要です。GitHubへ直接反映したZIPではありません。

## 今回の変更

- 再配置は日本時間の朝6時を基準に固定。同じ周期では完了したコマだけを予定から外し、ほかの予定を詰め直しません。閉じていた場合は6時以降に開く・戻ると更新します。履修や予定の変更も次の6時に反映します。
- 月の予定は先取りの余裕日数を使わず、実際の締切前へ配置。進捗ボタン・学習時間の範囲・「この枠で何分」を削除しました。足りない期間は土日の予備枠を優先します。
- 🍑の月の学習日数を、カレンダーの外に大きく表示。学習日の変更は歯車 → 学習記録に集約しました。
- TODAYは月カレンダーと同じ科目順で表示し、まだ完了していないコマの最初の締切を小さく表示します。不要な未完了文と操作説明を削除しました。進捗の「学期別進捗」カードも削除し、学期は上部から切り替えます。
- バッジ右上の☆をタップすると⭐になります。必要な下位の前提も自動で⭐になり、OR条件は1つの枝を選びます。科目選択で目標の必要科目・選択候補を強調し、「⭐ 目標科目」で絞り込めます。
- 目標科目の必要単位を重複なく集計し、卒業予定学期までの履修量を確認できます。卒研テーマなど追加条件があるバッジは別に表示し、科目一覧だけで総必要単位が確定しないことを示します。
- 歯車 → 履修設定から「毎学期の履修をシミュレーション」を追加。開始・卒業予定学期、1学期の目安単位を選び、卒業要件・年間上限・学習時間を確認し、1単位科目をなるべく前期と後期で半々にします。案の科目を移動・追加・削除でき、「履修設定に反映」するまで実際の履修は変わりません。
- コマをタップすると小テストの点数入力が開きます。点数と満点を保存して完了にするか、点数を後回しにできます。取消では記録を変えません。後から点数を編集できます。
- 進捗にGPA3.0の管理を追加。確定成績の当学期・累計GPA、小テスト平均、必要な残りの平均GPを表示。シラバスの評価配分を学習記録で登録すると予測GPAとB目標の期末点数を表示します。正式な成績と予測は別です。
- 各ページの操作・計算仕様は歯車 → 使い方・仕様に集約しました。
