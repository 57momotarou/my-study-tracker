# Study Tracker v71 更新手順

`study-patch-v71.zip` は、直前に配布したv70から変更・追加した公開用ファイルだけです。v70を適用済みのアプリへ上書きしてください。

## 更新

1. 歯車 → データから、更新前のバックアップを保存します。
2. ZIPを解凍して、中のファイルをGitHubの同じ場所へ上書きします。新しい `badge-candidates.js` も追加し、コミットしてください。ZIPそのものはアップロードしません。
3. 公開処理の完了後、オンラインでいつものアプリを開きます。歯車 → データでv71を確認し、必要なら「更新を確認」を押してください。

同じURLへの通常更新では、履修・進捗・成績・目標バッジ・自分の予定・生活時間を引き継ぎます。大学資料のJSONの読み直しや、ホーム画面への追加し直しは不要です。このZIPはGitHubへ直接反映したものではありません。

## 今回の変更

- 今日タブの一番上にあった期末・成績発表のお知らせカードを削除しました。日程データと締切の機能は残っています。
- バッジ画面に、目標へ向けて次学期に選ぶとよい科目を表示します。前提バッジの科目、選択グループ、分野別の必要単位を照合し、履修済み・履修中・完了済み・非開講を区別します。候補から次学期の履修設定を開けます。
- コマの着色だけで視聴・課題提出済みになります。別の課題チェックはなくしました。全コマと期末でその科目が完了し、成績はこれまでどおり別に登録できます。
- 以前の着色・課題記録は、いずれかで完了していれば完了として引き継ぎます。完了済みのコマは予定や未完了の締切から外します。
- 先取りおすすめはカレンダーの最初の割当日時順です。カードのコマ番号も、その最初の予定に合わせています。遅刻・直近7日以内の締切は引き続き優先します。
- 通常の学習枠で間に合わない期間は、土日の予備枠を優先して調整します。土日だけでは足りない場合はほかの予備枠も使い、締切前に入らない分は要調整として残します。勉強しない日・本人の予定・生活時間を守ります。
- 色を付けた日本時間の日付を学習日として保存し、月カレンダーに🍑を表示します。予定が組み直されても記録は残ります。期末の記録にも🍑がつきます。

## 🍑の学習日を変える

進捗で科目の「🍑 学習日を確認・変更」を開き、完了したコマ・期末の日付を変更してください。月カレンダーの🍑がある日をタップして、下の記録からも変更できます。深夜に前日の学習分を記録したときにも使えます。

複数のコマを同じ日に完了しても🍑は1つです。着色を解除すると、そのコマの学習日を取り消します。同じ日のほかの記録があれば🍑は残ります。以前の記録には日付を推測して付けません。日付が分かるものは後から入力できます。

## バックアップと検証

新しい出力はversion 5です。🍑の学習日と目標バッジを含めます。旧version 1〜4の復元にも対応します。v5の復元先はv71以降に更新してください。個人のバックアップや専用JSONは公開用ファイルに含めません。

JavaScript23ファイルの構文確認と、Node回帰68件を日本時間・UTCの両方で実施しました。月の表示内容、深夜の日付変更、再起動・バックアップ・保存失敗時の復旧、候補の条件、予定順、土日優先と締切境界を確認しています。今回の実ブラウザーの画面表示、iPhone実機／Safari、実際のGitHub公開先での確認は未実施です。
